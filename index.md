## 🎧 How to create music

You interact with the software using plain language commands in the Claude chat box. You do not need to manage settings or install extra plugins.

### Creating your first track
Type a description of the music you want into the chat box. For example: "Create an upbeat jazz track with a saxophone lead." The system processes your request and provides a download link for the resulting audio file.

### Adding vocals
You can ask the system to include vocals by typing: "Add a female vocal melody to the track." The software handles the layering and processing automatically.

### Matching a style
You can upload a reference file to help the system understand the sound you want. Provide the file path to a song on your computer and type: "Make a new song in the style of this file."

## 🛠️ Troubleshooting common issues

Most users find the setup process simple, but check these items if you run into trouble:

*   Check for updates: If you experience errors, visit the download page again to see if a newer version of SongForge-MCP exists. 
*   Permissions: Ensure your security software allows the application to access the internet.
*   Audio output: Check your Windows sound settings if you cannot hear the output file. Often, the system defaults to a disconnected audio device.
*   Restart: Close both the SongForge-MCP application and Claude Desktop, then restart both programs to refresh the connection.

## 📁 Managing your output files

The software saves each song to your computer as a high-quality audio file. You can find these files in your Documents folder under a subdirectory named "SongForge-Tracks." The software names each file based on the date and the style you requested. You can move these files to your preferred music library software or digital audio workstation for further editing if you choose.

## 🧠 Technology overview

This application relies on the Model Context Protocol to bridge the gap between your chat requests and the technical AI models powering the music generation. By using ACE-Step 1.5, the software maintains high fidelity in both the instrument stems and the vocal recordings. The stem splitting process isolates parts of the audio, which provides a professional finish without technical configuration.
